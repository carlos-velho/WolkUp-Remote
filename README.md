# WolkUp Remote

Projeto de assistência remota Windows, em desenvolvimento, para **WolkUp Balanças, Automação Comercial e Tecnologia**.

> **Estado atual:** planejamento e preparação. Ainda não existe executável WolkUp Remote compilado ou homologado.

## Produtos previstos
- **Cliente:** acesso remoto assistido por ID e autorização; modo instalado opcional.
- **Gerenciador:** console reservado à equipe técnica, para conectar-se a clientes autorizados.

## Base técnica
O projeto prevê adaptação do [RustDesk](https://github.com/rustdesk/rustdesk), sujeito à licença AGPL-3.0 e às licenças de suas dependências. Nenhum código do RustDesk foi copiado para este repositório nesta fase.
